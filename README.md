# RJ Connect

## 项目概览

本仓库提供一个 Zig 库，用于实现锐捷校园网认证所需的确定性协议引擎。库负责报文与字段编解码、认证状态转换、定时截止时间、待发送动作、直接通信分片重组和密码学原语。

本库不创建 socket、不发送链路层报文、不读取系统时钟、不管理凭据，也不实现 TLS。调用方负责驱动网络 I/O、时钟、随机数、TLS、凭据和平台状态，并根据库返回的动作完成实际发送。

本库不是完整客户端。调用方可以使用它构建客户端、离线报文验证器或其他协议工具，但网络生命周期和系统适配始终位于库外。

## 快速开始

需要与 `build.zig.zon` 声明一致的 Zig 版本。

```sh
zig build test
```

通过 Zig 包模块 `mentohust_zig` 使用库。调用方向协议引擎提交已接收的报文、当前时间和外部认证结果，并消费引擎返回的待发送报文、超时截止时间和状态变化。

## 开发验证

提交前至少执行：

```sh
zig fmt --check src build.zig
zig build test
```

现有测试验证字段编码、已知答案密码学向量和错误边界，不证明真实网络互操作。
